{# Shadcn-equivalent class-string macros, ported from OpenAlgo's own component source (app/components/ui/*.tsx) so buttons/cards/badges/inputs are pixel-faithful rather than approximated through DaisyUI's differently- designed .btn/.card classes. Each macro returns a class string to drop into a plain HTML element - Jinja has no clean equivalent of a React component wrapping arbitrary children, so callers write the tag themselves: Two deliberate departures from the original shadcn source: - `dark:` variants are dropped - AlgoMirror switches themes via a `data-theme` attribute (see theme.js), not Tailwind's own `dark:` class/ media-query variant, so those classes would silently respond to OS color-scheme instead of the app's toggle. - A few bracket-heavy arbitrary variants (`has-[>svg]:px-3`, `[&_svg:not([class*='size-'])]:size-4`, `ring-[3px]`) are dropped in favor of plain equivalents (ring-2) - SVG auto-sizing is moot anyway since every icon macro in macros/icons.html already takes an explicit size class at the call site. `shadow-xs` doesn't exist pre-Tailwind-v4 (this project is on 3.4), so `shadow-sm` stands in for it. Token names use the oaprimary/oasecondary/oaaccent prefix (not shadcn's bare primary/secondary/accent) because those bare names are already DaisyUI's own theme-color slots - see tailwind.config.js. #}
